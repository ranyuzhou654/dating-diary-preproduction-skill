# 后期说明（人工在剪辑软件中完成）

`assemble.py` 的粗剪只用来检查节奏。下面这些步骤在剪映或其他剪辑软件里做。

## 剪辑

- 全部硬切，不加淡入淡出。
- 按分镜表的“声音设计”列标出配乐进出点：幻想段切入时音乐进，切回现实时截断。
- 对白字幕在剪辑软件里加；片尾小字（如 “Dating Diary #N”）同样后加。
- 商用发布的音乐使用平台授权版本。

## 统一配音（推荐变声，不重新配音）

现实部分分多段生成，每段的人声音色可能不同。变声只换音色，保留原来的口型节奏和语气。

1. **定标准音色**：从满意的片段各截 10–30 秒干净人声。女主这段跨集长期复用，存为角色 profile 的 `voice_ref`。
2. **人声分离**：UVR5 或剪映“人声分离”，得到干人声 + 背景音。
3. **按角色切轨**：男女主台词分别导出。
4. **变声**：Seed-VC（零样本，给参考音频即可）；长期角色可训练 RVC；也可用 ElevenLabs Voice Changer。
5. **重新混音**：整段现实部分铺一条统一的环境音，压低或去掉各段原背景音，消除段与段之间的接缝。
6. **响度统一**。

个别句子念错、吞字时，用 IndexTTS2（可控时长）或 CosyVoice 单句重配，再按第 4 步变声，保持音色一致。

以上工具的界面和参数以各自当前文档为准。
